# راه‌اندازی ربات تلگرام اسکنر Ati

این پروژه از منطق اسکن Toobit Futures موجود در `server.js` استفاده می‌کند و در حالت `BOT_MODE=true` بدون باز بودن Chrome یا لپ‌تاپ اسکن می‌کند. ربات فقط تحلیل می‌کند و هیچ سفارشی ثبت نمی‌کند.

## انتشار روی Render

1. در Render از New > Blueprint استفاده کن و همین مخزن و شاخه `telegram-bot` را انتخاب کن.
2. Render تنظیمات `render.yaml` را می‌خواند. این پیکربندی از سرویس پولی Starter و یک دیسک پایدار برای فایل‌های `data` استفاده می‌کند؛ سرویس رایگان ممکن است بخوابد و برای پایش ۲۴ساعته مناسب نیست.
3. در تنظیمات Environment سرویس، مقدار محرمانه `TELEGRAM_BOT_TOKEN` را با توکن BotFather وارد کن. توکن را در کد یا فایل‌های GitHub قرار نده.
4. ابتدا سرویس را Deploy کن. سپس در تلگرام با ربات خودت گفتگو را باز کن و دستور `/id` را بفرست.
5. عدد شناسه‌ای که ربات پاسخ می‌دهد را در متغیر محرمانه `TELEGRAM_ALLOWED_USER_ID` در Render وارد کن. سرویس را Restart/Deploy کن. از آن پس فرمان‌های اسکن فقط از آن شناسه پذیرفته می‌شوند.
6. در تلگرام `/start` و سپس `/status` را بفرست. در حالت BOT_MODE اسکن بازار به‌صورت خودکار پس از شروع سرویس آغاز می‌شود.

## فرمان‌ها

- `/startscan` — شروع اسکن
- `/stop` — توقف اسکن
- `/status` — وضعیت و پیشرفت
- `/signals` — نمایش سیگنال‌ها
- `/capital 100` — سرمایه اختصاصی هر معامله به USDT
- `/leverage 10` — اهرم صرفاً برای محاسبه حجم؛ اهرم صرافی را تغییر نمی‌دهد
- `/scan priority`, `/scan favorites`, `/scan all` — حالت اسکن
- `/orders Market,Limit,Trigger` — انواع سفارش مجاز
- `/horizon fast` یا `/horizon normal` — افق بررسی
- `/favorite BTC-USDT`, `/unfavorite BTC-USDT`, `/favorites` — علاقه‌مندی‌ها
- `/pin BTC-USDT LONG`, `/unpin BTC-USDT LONG`, `/recheck BTC-USDT LONG` — پین و بررسی مجدد

## نکات مهم

- داده‌های بازار از API عمومی Toobit دریافت می‌شوند. در زمان قطعی API، سیگنال تازه تضمین نمی‌شود.
- سیگنال‌ها و سطح‌های Entry/SL/TP خروجی الگوریتمی‌اند و تضمین سود نیستند؛ پیش از استفاده واقعی باید با آزمون تاریخی و paper trading اعتبارسنجی شوند.
- دیسک پایدار برای نگه‌داشتن فایل‌های JSON در ری‌استارت لازم است.
- در صورت تغییر فایل‌های اسکنر یا خطای استقرار، ابتدا لاگ‌های Render را بررسی کن.
