# اسکنر اندروید Toobit Futures — نسخه v0.9.1

این نسخه اندروید بر اساس رابط و تنظیمات نسخه دسکتاپ شاخه `desktop-app-v0.9.1` ساخته شده است.

## امکانات
- فیلتر کاربرد ارز و ویژگی‌های بازار
- حالت اسکن: اولویت Favorites، فقط Favorites، یا تمام بازار
- انتخاب نوع سفارش Market / Limit / Trigger
- تحلیل چندتایم‌فریمی ۱ساعت، ۱۵دقیقه و ۵دقیقه با ایچیموکو، MACD و پرایس‌اکشن
- کارت‌های سیگنال، پین‌کردن و بررسی فوری مجدد کارت پین‌شده
- ذخیره تنظیمات، Favorites و کارت‌های پین‌شده در گوشی
- گزارش سریع بازار، شمارنده و نوار پیشرفت
- فقط تحلیل و پایش؛ هیچ سفارش واقعی ارسال نمی‌شود

## ساخت APK
GitHub Actions با هر push به شاخه `android-app`، APK آزمایشی را می‌سازد و به‌صورت Artifact ارائه می‌کند.

**توجه:** ساخت موفق APK به‌تنهایی تضمین نمی‌کند API زنده Toobit در همه شبکه‌ها در دسترس باشد. پیش از اتکا به خروجی‌ها، اتصال و نتایج تحلیل را بررسی کنید.
