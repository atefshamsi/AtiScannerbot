# اسکنر Toobit Futures — نسخه ۰٫۶

این نسخه یک داشبورد محلی برای تحلیل داده‌های عمومی بازار است. **هیچ سفارش واقعی ارسال نمی‌کند و اهرم را انتخاب یا تنظیم نمی‌کند.** این نسخه هنوز باید روی اتصال واقعی Toobit و خروجی‌های تحلیلی اعتبارسنجی شود؛ پیش از این اعتبارسنجی، از آن برای تصمیم‌گیری مستقیم معاملاتی استفاده نکنید.

## نیازمندی
- Windows 10/11
- Node.js نسخه ۱۸ یا جدیدتر (پیشنهاد: نسخه LTS جاری)
- Google Chrome
- اتصال اینترنت و دسترسی شبکه به API عمومی Toobit

## امکانات افزوده‌شده در نسخه ۰٫۶
- انتخاب هدف زمانی بررسی: سریع (۱۰ دقیقه) یا معمولی (۱ تا ۲ ساعت). این گزینه فعلاً افق ارزیابی را مشخص می‌کند؛ تضمین یا پیش‌بینی زمان سود نیست.
- دکمه «بررسی سریع بازار» گزارش تغییرات ۲۴ساعتهٔ قراردادها و ارزهای دارای بیشترین رشد/افت را از دادهٔ Futures نشان می‌دهد. این گزارش جهت قطعی آینده نیست.
- توضیحات کوتاه فارسی و تأکید بر اینکه نقدشوندگی و حجم باید جداگانه بررسی شوند.

## اجرا
1. فایل ZIP را از حالت فشرده خارج کنید؛ مثلاً در `C:\ToobitScanner`.
2. اگر Node.js نصب نیست، نسخه LTS را از سایت رسمی `https://nodejs.org/` نصب کنید.
3. روی `Start-Toobit-Scanner.bat` دوبار کلیک کنید.
4. داشبورد در Chrome با آدرس `http://127.0.0.1:4173` باز می‌شود. اگر Chrome در مسیر استاندارد نصب نشده باشد، برنامه مرورگر پیش‌فرض را باز می‌کند.
5. سرمایه هر معامله را به USDT وارد کنید و «شروع اسکن» را بزنید.
6. برای توقف، از دکمه «توقف» استفاده کنید. بستن تب باعث توقف اسکن پس از قطع heartbeat می‌شود.
7. برای خروج کامل، پنجره سرور Node را که به‌صورت کمینه اجرا شده است ببندید.

## پایش وضعیت سیگنال در نسخه ۰٫۴
- کارت پین‌شده بعد از هر بررسی نماد، زمان آخرین بررسی، قیمت مشاهده‌شده و وضعیت اعتبار را نمایش می‌دهد.
- وضعیت‌ها شامل «معتبر»، «معتبر با هشدار»، «در حال تضعیف»، «نامعتبر» و «شرایط دوباره مناسب» هستند.
- افت محسوس امتیاز، اختلاف تایم‌فریم‌ها یا عبور نکردن از فیلترها باعث نمایش هشدار می‌شود؛ کارت پین‌شده خودکار حذف نمی‌شود.
- وقتی امتیاز یا سطوح Entry/SL/TP تغییر معنادار کنند، تغییرات اخیر در خود کارت ثبت می‌شوند تا سطوح قبلی با جدید اشتباه نشوند.
- این وضعیت‌ها خروجی قواعد الگوریتمی هستند، نه تضمین نتیجه معامله. اتصال زنده و کیفیت سیگنال‌ها همچنان باید در محیط کاربر آزمایش شوند.

## داده و حریم خصوصی
- برنامه روی لپ‌تاپ اجرا می‌شود و داده‌های عمومی بازار را از API Toobit درخواست می‌کند.
- سیگنال‌های پین‌شده در فایل `data/pins.json` ذخیره می‌شوند.
- این نسخه هیچ API key، رمز عبور یا کلید خصوصی حساب را درخواست نمی‌کند.

## نکات فنی
- APIها بر اساس مستندات عمومی Toobit USDT-M Futures پیاده شده‌اند: `GET /api/v1/exchangeInfo`, `GET /quote/v1/contract/ticker/24hr`, `GET /quote/v1/contract/ticker/price`, و `GET /quote/v1/klines`.
- درخواست‌ها با صف و فاصله زمانی ارسال می‌شوند؛ اسکن تمام قراردادها ممکن است چند دقیقه طول بکشد.
- فیلتر اولیه امتیاز و محاسبات SL/TP الگوریتمی‌اند و هنوز با بک‌تست و paper trading اعتبارسنجی نشده‌اند.
- محاسبه حجم، تخمینی است؛ به‌ویژه multiplier، واحد مقدار و محدودیت‌های هر قرارداد باید در تست زنده برای نمادها تأیید شود.
- API عمومی Toobit ممکن است در دسترس نباشد، آدرس/ساختار پاسخ آن تغییر کند یا درخواست‌ها را محدود کند. در این حالت داشبورد باید خطا را نشان دهد و نباید داده قدیمی را قیمت زنده جا بزند.
- هنگام بستن Chrome، اسکن متوقف می‌شود. اطلاعات ذخیره‌شده سیگنال به‌تنهایی اعتبار زنده آن را تضمین نمی‌کند؛ پس از بازگشایی، باید داده تازه دریافت شود.

## فایل‌ها
- `server.js` — سرویس محلی، اتصال API، اسکن و ذخیره سیگنال‌های پین‌شده
- `public/index.html` — ساختار داشبورد
- `public/style.css` — طراحی واکنش‌گرا و راست‌چین
- `public/app.js` — کنترل رابط کاربری و ارتباط با سرویس محلی
- `data/pins.json` — سیگنال‌های پین‌شده (پس از ایجاد)

## عیب‌یابی
- اگر Chrome صفحه را باز نکرد، آدرس `http://127.0.0.1:4173` را دستی وارد کنید.
- اگر Node.js شناخته نشد، نصب Node را کامل کنید و دوباره BAT را اجرا کنید.
- اگر خطای API دیدید، اینترنت و دسترسی به `https://api.toobit.com` را بررسی کنید. از نمایش هرگونه سیگنال به‌عنوان زنده در حالت خطا خودداری کنید.


## بررسی فوری کارت پین‌شده (نسخه ۰٫۳)

در هر کارت پین‌شده، دکمه «بررسی فوری وضعیت» اضافه شده است. با فشردن آن، برنامه کندل‌های ۱ساعته، ۱۵دقیقه‌ای و ۵دقیقه‌ای و قیمت تازه همان قرارداد را از API عمومی Toobit دریافت می‌کند و وضعیت همان کارت را به‌روزرسانی می‌کند؛ نیازی نیست منتظر دور بعدی اسکن کامل بمانی. اگر دریافت داده تازه شکست بخورد، پیام خطا نمایش داده می‌شود و داده قبلی به‌عنوان بررسی جدید تأیید نمی‌شود. این دکمه سفارش ثبت نمی‌کند.


## رفتار قدیمی TP در نسخه ۰٫۴ (در نسخه ۰٫۵ جایگزین شده است)
- هدف دوم (TP2) برابر ۴ برابر فاصله ورود تا حد ضرر تنظیم شده است؛ کارت‌ها نسبت هدف ۱:۴ را نمایش می‌دهند.
- هدف اول (TP1) همچنان در ۱٫۵ برابر فاصله حد ضرر قرار دارد.
- این نسبت هدف محاسباتی است و تضمین نمی‌کند قیمت به TP2 برسد؛ الگوریتم هنوز بک‌تست/پیپر تریدینگ اعتبارسنجی نشده است.


## تغییرات نسخه 0.5 دسکتاپ
- اهرم محاسباتی کنار سرمایه اضافه شده؛ این گزینه فقط برای محاسبه حجم استفاده می‌شود و تنظیم اهرم صرافی را تغییر نمی‌دهد.
- TP1 بر اساس هدف سود 4٪ و TP2 بر اساس هدف سود 16٪ از سرمایه اختصاصی معامله محاسبه می‌شود؛ کارمزد نادیده گرفته شده است. نسبت واقعی سود به زیان از فاصله TP2 تا حد ضرر محاسبه و نمایش داده می‌شود؛ با ریسک هدف 0.5٪ این اهداف لزوماً نسبت 1:4 نیستند.
- Favorites برای هر نماد ذخیره می‌شود و سه حالت اسکن دارد: اولویت Favorites، فقط Favorites، تمام بازار.
- فیلتر نوع سفارش Market / Limit / Trigger ذخیره می‌شود.


## نسخه ۰.۸ — فیلترهای مستقل دسته‌بندی

- فیلتر نوع/کاربرد ارز و فیلتر ویژگی‌های بازار مستقل‌اند و می‌توان هرکدام را جداگانه یا هم‌زمان فعال کرد.
- در هر فیلتر، انتخاب چند گروه مجاز است. بین گروه‌های یک فیلتر، منطق «حداقل یکی از گزینه‌ها» اعمال می‌شود؛ اگر هر دو فیلتر فعال باشند، قرارداد باید از هر دو فیلتر عبور کند.
- گروه‌های کاربردی فعلاً با فهرست اولیهٔ نمادها مشخص می‌شوند و ممکن است یک ارز در بیش از یک گروه واقعی قرار بگیرد.
- گروه‌های بزرگ/متوسط در این نسخه فهرست اولیه‌اند، نه رتبه‌بندی زنده بر اساس ارزش بازار. «پرنوسان» با تغییر ۲۴ساعتهٔ حداقل ۸٪ و «هم‌جهت با BTC» با هم‌علامت بودن تغییر ۲۴ساعته (حداقل ۱٪ برای ارز) سنجیده می‌شود؛ این مورد، همبستگی آماری لحظه‌ای محسوب نمی‌شود.
- این محدودیت‌ها در رابط برنامه هم ذکر شده‌اند تا نتیجهٔ فیلترها بیش از واقعیت دقیق جلوه نکند.


## تغییرات نسخه ۰٫۸
- بازطراحی پنل هیرو و استفاده از فضای سمت راست با پنل نبض بازار.
- تغییر عنوان به «اسکنر هوشمند Ati».
- نمایش تغییر ۲۴ساعته BTC، حجم معاملات تجمیعی در پاسخ API، وضعیت کلی بازار، تعداد قراردادها و زمان گزارش سریع بازار.
- انتقال تنظیمات سرمایه، حالت بررسی، فیلترها و انواع سفارش به پنل مستقل زیر هیرو.
- نگه‌داشتن داشبورد پیشرفت و آمار اسکن در بخش جداگانه و چیدمان واکنش‌گرا برای حداکثر پنج کارت سیگنال.
- نمودار کوچک داخل هیرو در این نسخه نمایشی است و نباید به‌عنوان نمودار قیمت تاریخی زنده تفسیر شود.
